# Music Sources for Commercial Use

This guide lists sources for royalty-free, soft, and gentle music suitable for Instagram Reels and commercial use.

## Free Royalty-Free Music Sources

### 1. **YouTube Audio Library** (Recommended)
- **URL**: https://studio.youtube.com/channel/UC.../music
- **License**: Free to use, no attribution required for most tracks
- **Best for**: Soft instrumental, ambient, acoustic
- **How to download**: 
  1. Go to YouTube Studio → Audio Library
  2. Filter by "Instrumental" and "Mood: Calm/Peaceful"
  3. Download directly as MP3

### 2. **Free Music Archive (FMA)**
- **URL**: https://freemusicarchive.org/
- **License**: Various Creative Commons licenses
- **Best for**: Ambient, acoustic, instrumental
- **Filter**: Search for "ambient", "acoustic", "instrumental"

### 3. **Incompetech** (Kevin MacLeod)
- **URL**: https://incompetech.com/music/royalty-free/
- **License**: Free with attribution (Creative Commons)
- **Best for**: Soft background music, ambient tracks
- **Categories**: "Ambient", "Emotional", "Calm"

### 4. **Bensound**
- **URL**: https://www.bensound.com/
- **License**: Free with attribution for non-commercial, paid for commercial
- **Best for**: Soft, gentle background music
- **Categories**: "Acoustic", "Cinematic", "Emotional"

### 5. **Pixabay Music**
- **URL**: https://pixabay.com/music/
- **License**: Free for commercial use, no attribution required
- **Best for**: Ambient, acoustic, instrumental tracks
- **Search terms**: "ambient", "soft", "gentle", "acoustic", "meditation"

### 6. **FreePD**
- **URL**: https://freepd.com/
- **License**: Public domain, free for commercial use
- **Best for**: Classical, ambient, instrumental

## Paid Royalty-Free Music (Better Quality)

### 1. **Epidemic Sound** (Popular for Content Creators)
- **URL**: https://www.epidemicsound.com/
- **License**: Subscription-based, commercial use included
- **Best for**: High-quality ambient, acoustic, soft tracks
- **Price**: ~$15/month

### 2. **Artlist**
- **URL**: https://www.artlist.io/
- **License**: Subscription-based, commercial use included
- **Best for**: Professional-quality music
- **Price**: ~$9.99/month

### 3. **AudioJungle (Envato Market)**
- **URL**: https://audiojungle.net/
- **License**: Pay per track, commercial license available
- **Best for**: One-time purchase, specific tracks
- **Price**: $1-50 per track

### 4. **Pond5**
- **URL**: https://www.pond5.com/music
- **License**: Pay per track, commercial license available
- **Best for**: Wide selection, pay per use
- **Price**: Varies

## Quick Start Guide

1. **For Free Music**:
   - Start with **Pixabay Music** or **YouTube Audio Library**
   - Search for "ambient" or "acoustic"
   - Download MP3 files
   - Place them in `assets/00_music/`

2. **For Professional Quality**:
   - Consider **Epidemic Sound** or **Artlist** subscription
   - Great for consistent branding and high-quality tracks

3. **File Naming Convention**:
   - Use descriptive names: `soft_ambient_1.mp3`, `gentle_acoustic_2.mp3`
   - This makes it easier to select music for different themes

## Example Commands

Once you have music files:

```bash
# Use a specific music file
python main.py generate --theme 06_digestive_health --type reel --combined --music assets/00_music/soft_ambient_1.mp3

# Try different music for different themes
python main.py generate --theme 05_kombucha_benefits --type reel --combined --music assets/00_music/gentle_acoustic_2.mp3
```

## Legal Note

Always check the license before using music commercially. For Instagram business accounts:
- **Free sources**: Pixabay, YouTube Audio Library (check individual licenses)
- **Paid sources**: Epidemic Sound, Artlist (commercial licenses included)
- **Attribution**: Some free sources require attribution in video description

For your Kombucha business, consider:
